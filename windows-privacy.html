Windows Privacy Policy
Windows 版隐私政策

Effective date: September 23, 2026 · Applies to Xiaoluo AI Usage Pet for Windows distributed through Microsoft Store. Development previews may have Store billing disabled. This policy does not imply that the app has already been published or certified.

生效日期：2026 年 9 月 23 日。适用于通过 Microsoft Store 分发的小螺 AI 用量桌宠 Windows 版本。开发预览版可能尚未启用商店支付。本政策不表示应用已经发布或通过审核。

English

1. Who provides the app

Xiaoluo is provided by independent developer Puck Shen (Microsoft Store publisher: PUCKSHEN). For privacy, security, deletion or support questions, contact xiaoluoaiusage-feedback@outlook.com.

2. What is processed and why

Xiaoluo is a local Windows usage companion. After you connect a service, it processes the credentials you authorize, provider account and organization identifiers, names or email addresses, plan information, quotas, balances, costs and reset times needed to query and display your usage. Local aliases distinguish accounts. There is no separate Xiaoluo cloud account or developer-operated server collecting your credentials or usage data.

The app stores preferences, connection metadata, local aliases, notification settings and necessary operational records on your computer. Displayed account information and usage results may remain in memory while the app runs. Not all local metadata is secret or encrypted: credential protection described below applies to credential blobs and their key, not to every setting, screen or operating-system record.

Xiaoluo does not run AI inference, upload your prompts, conversations, code or documents to generate responses, or read other AI clients' sign-in files. It does not include advertising or analytics SDKs. Selecting a provider website opens that provider's own service, whose data practices apply separately.

3. How Windows credentials are protected

App-owned API keys, OAuth tokens and supported website-session credentials are stored as per-account AES-256-GCM encrypted blobs, additionally protected for the current Windows user with Windows data protection (LOCAL=user). The random vault data key is held in an exact, local-only Windows Generic Credential in Windows Credential Manager. Xiaoluo does not enumerate other applications' saved passwords. No separate password-manager installation or routine vault-password entry is required.

This is Windows user-level protection, not a guarantee of isolation from all software running as the same user, an administrator or malware. Package-specific credential names do not create an application-only access boundary. The current design does not promise TPM-backed storage, immunity to process compromise, or complete removal of every plaintext memory copy.

While refreshing, the app must make the necessary credential available in process memory and send it to the relevant provider over HTTPS. It uses bounded requests and timeouts and does not put credentials, raw response bodies or balances in diagnostic logs. HTTPS protects transmission; the intended provider receives the credential. Admin or Management keys may have broader provider permissions than the read-only operations Xiaoluo uses. Review the connection instructions and grant only the permissions required.

“Pause all queries” cancels app queries and clears the vault key arrays owned by the application. It does not revoke provider credentials, erase saved connections, or guarantee memory-forensic erasure. Resuming or restarting the app can reopen the protected vault automatically and resume querying, subject to provider limits. Normal refreshing can continue while the Windows screen is locked. Privacy masking hides displayed values; it is not an encryption boundary or a guarantee against screenshots or screen-reading tools.

4. Service-specific connections

Supported direct connections query the corresponding provider's account, plan, quota, balance or usage endpoints. Codex reset credits and expiry dates are read for display only; Xiaoluo does not redeem them. Kimi Code and DeepSeek credentials are used for their respective official usage and balance endpoints. Requests are not relayed through a Xiaoluo server.

MiniMax keys are used in the selected region. China Token Plan may optionally use a private app-owned sign-in window for credit information. The supported session is verified against the subscription account and saved encrypted with the connection. This credit route uses a non-public website endpoint, can change, and may require signing in again. Xiaoluo does not change the credit switch or read another browser's profile. Disconnecting removes the saved session with the account credentials.

Gemini subscription and Gemini API currently provide official website links. Xiaoluo does not obtain the website login credentials. Legacy project-monitoring connections, if present, use the explicitly supplied service-account credential through fixed Google OAuth and Monitoring HTTPS endpoints with read-only monitoring scope; request counts are not a remaining balance.

Antigravity connects after your action through an installed official local CLI. Xiaoluo invokes read-only usage, credit and settings commands, extracts only the needed credit-overage setting, and does not read the CLI credential store or modify its login or settings. The approved executable path and digest are stored encrypted. Optional automatic refresh can be disabled. A compatibility export connection reads only the file you selected and validates its identity and fields. Disconnecting removes Xiaoluo's connection, not the official tool, its login or the original export file. CLI output is bounded and is not written to diagnostics. The official CLI and provider remain responsible for their own authentication and data handling.

5. Purchases, trial and notifications

Permanent Pro is an optional one-time Microsoft Store purchase. Microsoft processes checkout, payment details, redemption codes and the Store account. Xiaoluo uses Store product prices and license status to grant, restore and verify access; it does not receive your payment-card details or Microsoft password. An optional 14-day local trial does not start automatic billing. Local trial-start, expiry and time-validation records are kept in Windows Credential Manager to prevent repeated trials. Necessary purchase-recovery records are also retained locally.

If Pro access ends, features and extra connections outside the Free tier are suspended; protected connection data remains available for later restoration or explicit removal. You can explicitly remove a connection at any time.

Quota alerts require your in-app choices and Windows notification availability. Notification text may expose usage information depending on privacy and Windows settings. Delivered notifications and their history are managed by Windows. Local reminder settings, deduplication and delivery-outcome records support notification behavior. Hiding values does not retroactively erase notifications already delivered.

6. Diagnostics and feedback

Local logs record timestamps, allowlisted event codes, exception type and HRESULT. They exclude credentials, raw account identities, endpoint URLs, response bodies and quota or balance values. Logs rotate by size; they are not automatically uploaded. A diagnostic summary can include app and OS versions, architecture, language, theme, connected-account/provider counts and recent event counts. It does not include keys, account identifiers, prompts, paths or device identifiers.

Feedback opens an editable email draft. The system email draft can include the diagnostic summary; Gmail and Outlook web links contain only the support address, app-version subject and blank issue template. Xiaoluo does not automatically send mail. Explicit copying replaces clipboard contents, which Windows or your clipboard tools may retain or synchronize. Review before sending, and do not include API keys or authorization codes. Your email address and any message or attachments you send are processed by the mail providers and used by the developer to respond. Contact the support address to request deletion of support correspondence; provider backups and legal retention may still apply.

7. Retention, removal and your controls

You may leave services disconnected, pause queries, turn off automatic startup or alerts, disconnect an account, reset the app or uninstall it. Disconnecting removes that connection's local metadata and encrypted credential. A successful in-app reset removes connections and associated vault keys, preferences and diagnostics, stops keep-awake and clears in-app alert deduplication. Cleanup failures are reported rather than treated as successful deletion.

Trial eligibility, purchase-recovery protection and provider cooldown records remain when required. Cooldown records contain hashed local account identifiers and waiting deadlines, not tokens or usage values; expired records are removed on later writes. Resetting does not grant another trial or bypass limits. Startup is disabled where Windows allows; Windows notification permissions, notification-center history and other system-managed settings remain under Windows control.

Uninstallation or Windows Settings reset normally removes package-local data but may leave orphan Credential Manager entries or older service keys. External backups and Windows logs have their own retention. Older vault formats require their supported migration path; external backups are not silently upgraded. Deletion does not guarantee forensic erasure.

These actions do not delete a provider account, revoke a provider-side API key or OAuth authorization, delete the original user-selected files, or erase Microsoft Store purchase records. Revoke access at the provider when needed. Xiaoluo has no developer-operated remote deletion service for your computer.

8. Third parties, website and updates

Connected providers, Microsoft, official local tools and your email service process the information needed for the actions you request under their own privacy policies, potentially outside your region. Xiaoluo does not sell personal data. This developer-oriented utility is not directed to children and does not request their age or profile.

This policy is hosted on GitHub Pages, with no advertising, analytics scripts, forms or third-party fonts on this page. GitHub may process IP addresses and access logs to operate and protect the site; see the GitHub Privacy Statement. Microsoft Store manages Store-edition updates. Material changes to Windows data handling will be reflected in this policy and its effective date.

简体中文

1. 开发者与联系

小螺由独立开发者 Puck Shen 提供，微软商店发布者名称为 PUCKSHEN。隐私、安全、删除或支持问题请联系 xiaoluoaiusage-feedback@outlook.com。

2. 处理哪些数据、为什么处理

小螺是本地运行的 Windows 用量工具。主动连接服务后，应用处理您授权的凭据，以及服务商返回的账户和组织标识、名称或邮箱、套餐、额度、余额、费用与重置时间，用于查询和展示用量。您可使用本地别名区分账户。无需另注册小螺云端账户，也没有接收这些凭据和用量数据的开发者服务器。

偏好、连接元数据、账户别名、通知配置及必要运行记录保存在本机；账户信息与用量结果可能在运行期间保留于内存。并非所有本地数据都加密：下述凭据保护针对凭据密文及其密钥，不代表每项设置、屏幕内容或系统记录均受到同样保护。

小螺不调用 AI 模型生成回答，不为此上传提示词、聊天、代码或文档，也不读取其他 AI 客户端的登录文件。不包含广告或分析 SDK。您主动打开的服务商官网由该服务商单独处理数据。

3. Windows 凭据保护

应用持有的 API Key、OAuth Token 及支持的网页登录会话按账户保存为 AES-256-GCM 密文，并叠加当前 Windows 用户范围的数据保护（LOCAL=user）。随机保险库数据密钥保存在 Windows 凭据管理器中指定的、本机范围的通用凭据项。小螺不枚举其他软件保存的密码；无需另装密码管理器或日常反复输入保险库密码。

这是 Windows 用户级保护，不是对同一用户运行的所有软件、管理员或恶意程序的绝对隔离。以包身份区分凭据名称也不等于仅本应用可访问。当前方案不承诺 TPM 硬件保护、进程被劫持后仍安全，或能彻底消除内存中的所有明文副本。

刷新时，应用必须在进程内使用必要凭据，并通过 HTTPS 发给对应服务商。请求有大小和时间限制；诊断日志不保存凭据、原始响应或余额。HTTPS 保护传输，但接收方服务商仍会收到凭据。部分 Admin、Management Key 在服务商侧可能拥有比小螺只读查询更广的权限，请按连接说明仅授予所需权限。

“暂停所有查询”会取消查询并清理应用自行持有的保险库密钥数组，不会撤销服务商凭据、删除已保存连接，也不保证内存取证无法恢复。恢复查询或重启应用后可自动重新读取受保护凭据，并遵守服务商限流继续查询。Windows 锁屏期间常规刷新仍可继续。隐藏额度仅减少界面数值披露，不是加密边界，也不保证防截图或防屏幕读取。

4. 服务连接的特殊说明

直接连接只向对应服务商查询账户、套餐、额度、余额或用量。Codex 重置券数量和到期时间仅用于展示，不兑换。Kimi Code 与 DeepSeek 分别使用其官方用量、余额接口。请求不经过小螺服务器。

MiniMax 密钥仅用于选定区域。中国区 Token Plan 可选在应用私密窗口登录查询积分；支持的会话会核对订阅账户并随连接加密保存。积分路径属于非公开网页接口，可能变化或要求重新登录。应用不修改积分开关、不读取其他浏览器资料；断开时删除已保存会话及账户凭据。

Gemini 订阅和 Gemini API 当前为官网入口，不获取网页登录凭据。如存在旧版项目监控连接，则仅使用您明确提供的服务账户凭据，以只读监控权限请求固定 Google OAuth 和 Monitoring HTTPS 接口；请求统计不等于剩余额度。

Antigravity 在您主动操作后通过已安装的官方本机 CLI 连接。小螺只调用用量、积分和设置读取命令，从设置中提取所需的积分超额开关状态，不读取 CLI 凭据库、不修改其登录或设置。经确认的执行文件路径和摘要加密保存，可关闭可选自动刷新。兼容的本地导出连接只读取您选定的文件并核验身份及字段。断开小螺不会删除官方工具、其登录或原始文件；命令输出有大小限制，不写入诊断日志。官方工具自身的授权与数据处理由其负责。

5. 购买、体验与通知

永久 Pro 是可选的 Microsoft Store 一次性内购。付款资料、兑换代码和微软账户由微软处理；小螺读取商品价格与许可证状态以授予、恢复或核验权限，不接收银行卡资料或微软账户密码。可选的本地 14 天体验不会自动扣费。体验开始、到期和时间校验记录保存在 Windows 凭据管理器，防止重复领取；必要的购买恢复保护记录也保存在本机。

失去 Pro 权限后，超出免费版的功能和连接暂停，受保护的连接数据保留，供以后恢复或主动移除。您可随时主动移除连接。

额度提醒受应用开关和 Windows 通知设置控制；内容可能随隐私设置显示用量。已送达通知和通知历史由 Windows 管理。本地提醒设置、去重及投递结果记录用于支持通知功能。隐藏额度不会追溯删除已经送达的通知。

6. 诊断与反馈

本地日志仅记录时间、允许的事件代码、异常类型和 HRESULT，不含凭据、原始账户身份、端点网址、响应正文、额度或余额；按大小轮换，不自动上传。诊断摘要可能含应用和系统版本、架构、语言、主题、连接账户/服务商数量及近期事件计数，不含密钥、账户标识、提示词、路径或设备标识。

反馈打开可编辑邮件草稿：系统邮件草稿可包含诊断摘要；Gmail、Outlook 网页入口仅带支持地址、应用版本主题及空白问题模板。小螺不会自动发送。主动复制会替换剪贴板，Windows 或剪贴板工具可能保留或同步内容。发送前请检查，不要发送 API Key 或授权码。您主动发送的邮箱地址、正文及附件由邮件服务商处理，开发者用于回复问题；可通过支持邮箱请求删除，邮件备份与法定保留仍可能适用。

7. 保留、删除与控制

您可不连接服务、暂停查询、关闭登录启动和通知、断开账户、重置或卸载。断开会删除对应本地连接元数据和凭据密文。应用内重置成功后删除连接及相关保险库密钥、偏好和诊断，停止防休眠并清理应用内通知去重记录；清理失败会明确提示。

必要的体验资格、购买恢复保护和服务商限流记录仍会保留。限流记录包含哈希后的本地账户标识及等待截止时间，不包含令牌或额度；过期记录在后续写入时清理。重置不会重新授予体验或绕过限流。在 Windows 允许时关闭登录启动；系统通知权限、通知中心历史及其他系统设置由 Windows 管理。

卸载或 Windows 设置重置通常移除包内数据，但可能留下无法关联数据的凭据管理器项目或旧服务密钥。外部备份和系统日志按各自规则保留。旧保险库须按支持的路径迁移，不会自动升级外部备份。不保证法证擦除。

这些操作不删除服务商账户、不撤销服务商侧 Key 或 OAuth 授权、不删除您选择的原始文件，也不删除微软商店购买记录；需要时请在服务商后台撤销授权。小螺没有开发者远程删除您电脑数据的服务。

服务商、微软、官方本机工具及邮件服务商按各自政策处理您所请求操作必需的信息，处理地点可能在您所在地区之外。小螺不出售个人数据。本工具面向开发者用量管理，不面向儿童，不要求提供年龄或儿童资料。

本网页由 GitHub Pages 托管，不含广告、分析脚本、表单或第三方字体。GitHub 可能为运行和保护网站记录 IP 地址及访问日志，见 GitHub 隐私声明。商店版本由 Microsoft Store 管理更新；Windows 数据处理有重大变化时将同步更新本政策及生效日期。
