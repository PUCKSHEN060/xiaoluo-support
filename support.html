小螺支持 / Xiaoluo Support

小螺 AI 用量桌宠是一款适用于 macOS 13 及以上版本的菜单栏用量工具，由独立开发者 Puck Shen 提供。

Xiaoluo AI Usage Pet is a menu bar usage utility for macOS 13 and later, provided by independent developer Puck Shen.

联系我们 / Contact

支持、功能建议、隐私或删除请求：xiaoluoaiusage-feedback@outlook.com。也可在“小螺设置 → 关于”中使用反馈入口。请说明应用版本、macOS 版本、遇到问题的服务和重现步骤；发送前检查邮件，不要附上密码、授权码、API Key 或完整账单。

For support, feature requests, privacy, or deletion questions, email xiaoluoaiusage-feedback@outlook.com, or use the feedback action in Xiaoluo Settings → About. Include the app version, macOS version, affected service, and steps to reproduce. Review your message before sending; do not include passwords, authorization codes, API keys, or complete billing records.

启动后找不到窗口 / Where is the window?

小螺启动时只显示菜单栏图标和桌面额度气泡。点击菜单栏图标，或右键点击气泡，可进入 AI 用量总览与设置。旧窗口不会在重新启动时自动打开。

At launch, Xiaoluo shows its menu bar icon and desktop quota bubble. Click the menu bar icon or right-click the bubble to open AI Usage Overview or Settings. Previously open windows do not reopen automatically.

连接与刷新 / Connections and refresh

进入“小螺设置 → 连接管理”，主动添加服务并按说明授权。服务商网页或其他应用中已有的登录不会自动添加到小螺。不同服务可能要求浏览器授权、API Key、Admin Key 或 Management Key；请阅读该服务的权限说明。

Go to Xiaoluo Settings → Connections, add a service, and follow its authorization instructions. An existing login in a browser or another app does not automatically add it to Xiaoluo. Depending on the service, you may need browser authorization or an API, Admin, or Management key. Read that connection's permission notes.

如果额度没有更新，请先检查网络、对应账户是否仍有效以及页面的数据状态。缓存数据不是刚刚刷新的数据；服务商限流时，连续点击刷新不会提高数据新鲜度。某些套餐或接口不提供全部指标，小螺不会据此编造数据。可先在服务商官方页面核对，再联系支持。

If usage has not updated, check your network, account access, and the displayed data state. Cached data is not a new sample. Repeated refresh clicks do not make data fresher while a provider is rate-limiting requests. Some plans or APIs do not supply all metrics; Xiaoluo does not invent missing values. Check the provider's official page before contacting support.

没有收到额度提醒 / Missing alerts

确认 Pro 或体验资格有效、小螺通知总开关及对应服务开关已开启，并在 macOS“系统设置 → 通知”允许小螺通知。检查专注模式、横幅样式、提醒值和当前账户的最新数据；可使用应用内“发送测试通知”及“最近提醒记录”辅助排查。macOS 接受请求不保证显示横幅。同一账户、指标和周期的重复提醒会被抑制；提醒不会停止服务商消费。

Check that Pro or trial access is active, the app-wide and service alert switches are enabled, and macOS System Settings → Notifications allows Xiaoluo notifications. Check Focus, banner style, the configured threshold, and fresh data for the affected account. Use Send Test Notification and Recent Alert Records in the app to help diagnose delivery. macOS accepting a request does not guarantee a banner. Repeated alerts for the same account, metric, and period are suppressed; alerts do not stop provider spending.

免费、体验与恢复购买 / Free, trial, and restore

免费版没有使用期限，可使用一个服务的一个账户。每台 Mac 可主动领取一次 14 天 Pro 体验，不会自动扣费。永久 Pro 是一次购买，不是自动续期订阅。恢复时请登录原购买 Apple 账户、保持联网，并在 Pro 窗口选择“恢复购买”。需要退款时，请通过 Apple 的退款入口处理。

Free has no time limit and supports one account for one service. Each Mac can start one optional 14-day Pro trial with no automatic charge. Permanent Pro is a one-time purchase, not an auto-renewable subscription. To restore, sign in with the purchasing Apple Account, connect to the internet, and choose Restore Purchases in the Pro window. For a refund request, use Apple's refund service.

每次失去 Pro 后，额外连接暂停并保留 3 天；期间恢复 Pro 可继续使用。过期清理后需要重新连接，但服务商账号和订阅不会删除。重置或重新安装小螺不保证新的试用资格。

Each time Pro access ends, extra connections pause and are retained for 3 days. Restore Pro during that period to continue using them. After expired connections are cleaned up, reconnect them; provider accounts and subscriptions are not deleted. Resetting or reinstalling Xiaoluo does not promise another trial.

删除本地数据 / Local data removal

可在连接管理中断开单个账户或服务，也可使用“关于”中的重置入口。重置会保留本机试用资格记录，不影响 App Store 购买记录或服务商账号。仅删除应用文件不保证删除钥匙串和偏好。若还需要撤销服务商授权或密钥，请在服务商后台操作。

Disconnect an account or service under Connections, or use the reset action in About. Reset retains the local trial eligibility record and does not change App Store purchases or provider accounts. Removing the app file alone does not guarantee removal of Keychain items or preferences. Revoke provider-side authorization or keys in the provider's own settings if needed.

网站与隐私 / Website and privacy

本支持网站为静态页面，不提供登录或在线表单，不加载广告、分析脚本或第三方字体。页面由 GitHub Pages 托管；访问时 GitHub 可能为服务和安全目的处理 IP 地址与访问日志，详见 GitHub 隐私声明。这与小螺应用内的数据处理不同。

This support website is static, with no sign-in or online forms and no advertising, analytics scripts, or third-party fonts. It is hosted on GitHub Pages; GitHub may process IP addresses and access logs for service and security purposes under its privacy statement. This is separate from data handling in the Xiaoluo app.
